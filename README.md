# Stess-tension应力分解

为了深入了解构造地质学中应力应变知识，本人创建了一个三维展示窗口

应力：单位面积所受的内力。与物理学中的里不同，应力还与面积有关，单位是Pa/GPa

提出一个问题：为什么要有应力张量？

我认为应力张量一方面是便于简化计算，是将应力拆分成应力张量矩阵和面积矩阵乘积。应力张量是一个三行三列的矩阵。
